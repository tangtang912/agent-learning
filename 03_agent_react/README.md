# 练习 03：ReAct Agent（思考-行动-观察循环）

## 功能说明
- Agent 严格遵循 **ReAct（Reasoning + Acting）** 框架
- 按 **思考 → 行动 → 观察 → 再思考** 的流程逐步解决问题
- **每轮仅能调用一个工具**，禁止同时调用多个工具
- 显式展示思考过程、工具调用原因和观察结果

## 核心知识点
- **ReAct 框架**：推理与行动相结合的智能体范式
- **单工具限制**：通过系统提示约束 Agent 每轮只调用一个工具
- **多步推理**：解决需要多步才能完成的问题（BMI 计算需要先获取身高和体重）
- **`stream_mode="values"`**：逐次获取完整状态，观察 Agent 的每一步
